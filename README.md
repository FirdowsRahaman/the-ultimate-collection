## <img src="assets/icons/plus.svg" width="22" height="22" align="center" /> How to Add a Repository <a id="how-to-add-a-repository"></a>

Found a repository or tool that saves you hours? Add it!

1. Check the appropriate category table above.
2. Ensure the link points directly to the active GitHub repository.
3. Append a new row formatted as follows:

```markdown
| [Project Name](https://github.com/username/project) | Concise one-line summary of what it does | Category / Tag |
```
